## 再現手順・自動検証

Python 3.12、Pillow 10.2、NumPy 2.2.6、Matplotlib 3.10.3、FFmpeg 7.0.2をWSLで使用。追加依存はworkspaceの `.research/writer-video-quality/timeline-deps/` に配置し、ファームウェアの依存には追加していない。

`--manifest` は動画・log・既存測定JSON・cornersのパスを指定するJSON。今回のmanifestは `.research/writer-video-quality/timeline-manifest.json`。実行例：

```sh
python3 tests/hil/analyze_writer_contrast_timeline.py \
  --manifest .research/writer-video-quality/timeline-manifest.json \
  --output-dir .research/writer-video-quality/timeline/new-run \
  --ffmpeg /path/to/ffmpeg
```
